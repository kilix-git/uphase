# Hardware

- `kicad/` - KiCad projects (PiHat-to-Pico adapter, box wiring).
- `datasheets/` - datasheets of the parts used.
- `bom.csv` - bill of materials. `status` is one of: have, ordered, todo,
  undecided, idea.
