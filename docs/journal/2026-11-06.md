# 2026-11-06 - Project start, state of things

## Done

- Repository created as the single place for progress, ideas, measurements
  and decisions.
- PZEM-004T reader script written ([host/pzem-poc/pzem.py](../../host/pzem-poc/pzem.py)):
  Modbus RTU over a USB-UART at 9600 baud, prints voltage, current, power,
  energy, frequency and power factor once per second. Not yet tested on real
  hardware.

## Hardware state

- **Host:** Clockwork uConsole with a Raspberry Pi CM5 8GB Lite.
  Running Rex's Debian 12 Bookworm lite image (kernel 6.12). Rex's Trixie
  7.1.4 lite image failed to boot, so Bookworm it is for now.
- **Measurement board:** IPEM PiHat Lite (ATM90E36). It will be driven by a
  Raspberry Pi Pico over SPI instead of sitting on a Pi.
- **Current sensing:** iron-core split CTs. Rogowski coils maybe later.
- **Voltage sensing:** small 230V/9V mains transformers, one per phase. Not
  tested yet.
- **Proof of concept:** PZEM-004T + CP2102 USB-UART, on order.

## Decisions

- Pico as the front-end MCU - [0001](../design/0001-pico-as-mcu.md)
- Iron-core split CTs now, Rogowski later - [0002](../design/0002-split-cts-vs-rogowski.md)
- Wired USB link instead of wifi - [0003](../design/0003-wired-usb-link.md)
- Front end in a separate insulated box - [0004](../design/0004-isolated-front-end-box.md)

## Open questions

- Box power: from the uConsole over USB, or a separate 230V/5V supply?
- Do the 230V/9V transformers behave well enough (linearity, phase shift,
  load regulation, temperature)?
- Protocol between Pico and uConsole.
- ATM90E36 calibration procedure.
- Rogowski coils: when, which, and what integrator.
