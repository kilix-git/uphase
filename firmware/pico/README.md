# Pico firmware

Firmware for the Raspberry Pi Pico 2 (RP2350) in the front-end box: reads the
ATM90E36 on the IPEM PiHat Lite over SPI and sends measurements to the
uConsole over USB.

Not started yet (milestones `v0.2-pihat-alive`, `v0.3-pico-usb-link`).
See [design/0001](../../docs/design/0001-pico-as-mcu.md).
